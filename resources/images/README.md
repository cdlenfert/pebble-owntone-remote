# Icon Placeholders

This directory contains action bar icons for the OwnTone Remote app.

## Required Icons

All icons should be **25x25 pixels**, **PNG format**, with **transparency**.

### Icons Needed:

1. **icon_play.png** - Play button (triangle pointing right)
2. **icon_pause.png** - Pause button (two vertical bars)
3. **icon_next.png** - Next track (triangle pointing up or double arrow up)
4. **icon_prev.png** - Previous track (triangle pointing down or double arrow down)

## Creating Icons

You can:
1. Use the Pebble design resources from https://developer.pebble.com/
2. Create your own 25x25 pixel icons
3. Use existing open-source icon sets (with proper attribution)

## Temporary Solution

For now, you can copy standard Pebble icons from another project, or create simple geometric shapes:
- Play: Right-pointing triangle
- Pause: Two vertical rectangles
- Next: Upward-pointing triangle or chevron
- Previous: Downward-pointing triangle or chevron

The icons should be white on transparent background for best visibility on the action bar.
